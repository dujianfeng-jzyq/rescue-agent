# 报告格式

> 状态：草稿，格式待指挥部和客户确认。

通用要求：第一行是结论；数值注明来源（“计算结果”“监测数据”“估算”）；缺失数据单独列出；时间用矿井时间。

## 预警研判报告

```
【预警研判】<工作面> <矿井时间>
结论：建议预警等级 <等级>（<一句话原因>）
实时报警：<无 / 报警内容>
关键指标（计算结果）：
- <指标>：<数值>（阈值 <阈值>）
- ...
趋势：<测点> 近 24 小时 <上升/平稳/下降>，速率 <x>/h
数据质量：<被排除的测点及原因；无则写“无异常”>
需人工判断：<如有>
```

## 防灭火方案说明

```
【防灭火方案】<方案编号> <标题>
目标：<把哪个指标降到什么水平>
措施（按顺序）：
1. <措施>：<参数>（依据：<文档> <条号>）
...
效果观测：<测点、频次、判定标准>
物资：<调度单编号或草案>
红线自查：<通过 / 问题清单>
```

## 指挥部研判报告

```
【指挥部研判】<矿井时间>
结论：<火情阶段、最主要风险>
一、火灾情况 … 六、预案及实施状况（按第73条六类逐项，缺失项写“缺失，需 …”）
受威胁人员（估算）：<组数、人数、最早到达时间>；撤人按预案立即执行，本名单为补充
爆炸危险性：<结论>（仅考虑甲烷）
建议下一步：<…>
```

## 复盘报告（草稿）

```
【复盘】<事件编号> <起止时间>
时间线：<时间 — 事件/建议/确认/拒绝>
决策点：<每次人工确认或拒绝，确认人，依据>
偏差：<建议与实际处置不一致之处及原因>
改进项：<…>
```
复盘所需的指令台账在 `var/audit/tool-actions.jsonl` 和 `var/actions-ledger.jsonl`；会话日志由 DSH 保存。
